## 2.1 ノート名の表記系（重要）

**マニュアル / KSMap / sfz と Studio One で 1 オクターブずれる。**

| 表記系 | 規約 | 中央ド | MIDI 127 |
|---|---|---|---|
| マニュアル・KSMap・sfz | C-1 = 0 | C4 = 60 | G9 |
| **Studio One（ヤマハ式）** | **C-2 = 0** | **C3 = 60** | **G8** |

> **Studio One 上のノート名は、マニュアル表記より 1 オクターブ低く表示される。**

換算表（ランドマーク）:

| MIDI | マニュアル表記 | Studio One 表記 | 意味 |
|---|---|---|---|
| 11 | B-1 | B-2 | Stop_Key |
| 24 | C1 | C0 | Sus_Down |
| 35 | B1 | B0 | 発音域下限（7弦開放） |
| 60 | C4 | C3 | 中央ド |
| 86 | D6 | D5 | 発音域上限 |
| 91 | G6 | G5 | Bending_HT |
| 102 | F#7 | F#6 | Trill_Maj3 |
| 105 | A7 | **A6** | 注釈ブロック下限 |
| 127 | G9 | **G8** | 注釈ブロック上限 |

**実装方針: 内部処理はすべて MIDI ノート番号（整数）で行う。**
ノート名は UI / ログ表示のみで使い、その際は必ず番号を併記し、
表記系を設定で切り替えられるようにする（既定 = Studio One 式）。

## 2.2 音域マップ

```
  0 ─────────────────────────────────────────────────────── 127
      [11–34 下段KS]  [35–86 発音域]  [91–102 上段KS]  [105–127 注釈]
                                    ^^^ 87–90, 103–104 は緩衝帯（未使用）
```

`[sfz]` による裏取り:

| opcode | 値 | 意味 |
|---|---|---|
| `lokey=b1` | 35 | 発音域下限 |
| `hikey=d6` | 86 | 発音域上限 |
| `sw_lokey=e-1` / `f0` | 4 / 17 | KS 宣言域の下限 |
| `sw_hikey=d7` / `g#7` | 98 / **104** | KS 宣言域の上限 |

→ **MIDI 105–127 は KSOP パッチ内で完全に未使用**。注釈ブロックとして安全に転用できる。

## 2.5 CC24 Rel_Shape（最重要 CC）

ノートオフ時のリリース挙動を決める。`[説明]` は「重要な機能の一つであり、
エレキギターの打ち込みをよりナチュラルに仕上げます」と明記。

### リリーススタイル

| 値 | スタイル |
|---|---|
| 02–15 | Basic |
| 16–31 | Hard |
| 32–47 | Aggressive |
| 48–63 | Aggressive2 |
| 64–79 | **Position Change** ← フレットボードモデルと直結（§04-8） |

### アクションリリース（上記と値域が重なる。挙動が加算される）

| 値 | 挙動 | 対象アーティキュレーション |
|---|---|---|
| 80–127 | **自動スライドアウト** | サステイン、スライドダウン/アップ、プリング、ハンマリング、スライドイン、擬似レガート<br>（ミュートダウンのリリースはアップストロークになる） |
| 96–127 | **自動オルタネイト** | サステインダウン、ミュートダウン、フレットミュートダウン、ブラッシングダウン<br>→ リリース音がアップストロークになる |

**実装上の含意:**

- フレーズ末に KS 34 (`slide_out`) を個別に打つ必要はない。
  **CC24 を 80–127 にすれば音源側が自動でやる**
- リリース音はノートオフから次のノートオンまで鳴り続ける。
  強制停止したい場合は **MIDI 11 (Stop_Key) を打つ** `[説明]`

## 2.6 CC26 / CC27 スライド距離テーブル `[説明]`

CC26 = スライドアップ / ダウン、CC27 = スライドイン。値域は共通。

| 距離 | 半音数 | CC 値域 | **推奨出力値** |
|---|---|---|---|
| 半音 | 1 | 01–15 | **8** |
| 1音 | 2 | 16–31 | **24** |
| 1音半 | 3 | 32–47 | **40** |
| 2音 | 4 | 48–63 | **56** |
| 2音半 | 5 | 64–79 | **72** |
| 3音 | 6 | 80–95 | **88** |
| 3音半 | 7 | 96–127 | **112** |

推奨出力値は各値域の中央付近。境界値を避けることで、DAW 側の丸めや
補間による誤爆を防ぐ。

## 2.7 KS / CC の配置規則 `[実測]`

メーカー製サンプル MIDI 9 本を解析して確認した事実。すべて `tpq = 960`。

### ① 下段 KS は実音と同一 tick に置く（トラック内で KS が先）

`Standard_Guitar_Demo.mid` trk2 の下段 KS のうち **362 / 369 個が lead = 0**。
`mido` はトラック内のイベント順序を保持するため、同一 tick でも KS を先に書けば正しく効く。

### ② 上段 KS は先行させるのが安全

`[説明]` は「G6〜F#7 にアサインされているアーティキュレーションを使用する場合、
キースイッチのノートを実音より前に配置する必要があります」と明記。

実測ではデモの上段 KS 47 個中 45 個が lead = 0 で動作しているが、
ポルタメント（KS 96）のみ **101 tick 先行**（tpq 960 ≒ 1/9.5 拍）。

→ **安全側に倒し、全 KS に `tpq/32` の先行オフセットを与える**（§2.8 の理由も参照）。

### ③ KS 34 (Slide_Out) だけはリリース側に置く

`Anti_Machingun.mid` trk2 では KS 34 が「次ノートの 240 tick 前」＝
直前の音の離し際に配置されている。他の KS と配置規則が異なるため、
レンダラは **発音前 KS** と **リリース KS** を区別する必要がある。

### ④ KS はラッチする。毎音再送しても無害

デモは `sus_alt` を 168 回、`mute_alt` を 133 回連投している。
冪等に書けるため、実装は「イベントごとに必ず KS を出す」で問題ない。
`--dedup` オプションで連続同一 KS の抑制を選べるようにする。

### ⑤ 和音は KS 1 個が全体を支配

最大ポリフォニーは 7（＝7 弦）。和音内の音ごとに KS を分ける必要はない。

### ⑥ CC は対象ノートの直前に置けば効く

`CC22_Mute_Control.mid` 等で確認。KS と同じ先行オフセットに載せてよい。

## 2.8 KS を分離トラックに出す場合の必須条件

本ツールは生成 KS/CC を専用トラック `AutoSG_KS` に出力する（§05）。

> **トラックをまたぐと同一 tick のイベント順序は保証されない。**
> したがって分離トラック方式では**全 KS に先行オフセットが必須**である。

`tpq/32`（tpq=960 なら 30 tick）を既定とする。サンプル MIDI のポルタメントが
101 tick 先行していることから、この程度の先行は音源側の想定内である。

`--inline` で実音トラックにマージする場合も、同じオフセットを維持してよい
（メーカーデモと完全一致させたい場合のみ `--ks-lead 0` を指定）。

## 2.9 運用上の注意（音源側の制約）`[説明]`

実装で回避すべき / ユーザーに警告すべき事項。

| 事項 | 内容 | ツールでの扱い |
|---|---|---|
| オルタネイトの RR 非復帰 | KS 26 / 29 はラウンドロビンが自動復帰しない | Alt を使わず Down/Up 明示（§04-1） |
| 上段 KS の先行 | G6〜F#7 は実音より前に置く必要がある | 全 KS に `tpq/32` 先行（§2.8） |
| 音切れ | サステイン選択中に発生しうる | Sforzando 側の設定（Max Engine RAM / Disk Pre-Caching を最大）。README で案内 |
| リアルタイムバウンス推奨 | 高速書き出しでエラーが出る場合がある | README で案内 |
| 発音域外 | 35 未満 / 86 超は発音しない | バリデーションで警告（§05） |
